# Cobaya Clicker

Juego clicker de cobayas en un solo archivo HTML. Abre `index.html` en el navegador para jugar.

- Clica la cobaya para conseguir zanahorias
- Compra mejoras, atuendos y personajes
- Sube de nivel para cambiar de escenario: Jaula, Salón, Jardín, Castillo y Espacio
- Medallas por clics y autoclic
